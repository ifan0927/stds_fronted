頁面與操作狀態

page-level state 用於整頁不可用；toast 用於短暫結果；blocker 保留在流程區塊內。
Foundation state surfaces
Loading
保留 header、filter 和表格骨架，避免空白頁。
Empty
目前物業沒有已到期或已退租租約，提供返回租約名冊的入口。
Forbidden
目前角色或物業權限不足；不要把 403 呈現成空清單。
Not found
租約或強制終止記錄不存在，提供返回 review list。
Stale preview
409 或 preview token mismatch 時，停用 finalize 並要求重新 preview。
Validation
reason / deposit_handling 必填錯誤留在表單欄位附近。
Export failure
用 toast 或 inline alert 提供重試，不承諾 PDF 或儲存檔案。
Success
完成退租後 refetch lease、room、bill、review list，並顯示 toast。
