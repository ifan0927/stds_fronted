# 07 日誌與維修工作區

本章適用於需要建立維修單、查看維修列表、指派維修、更新維修狀態、上傳施工照片或其他文件，以及理解維修完成後房間狀態會重新讀取的使用者。主要入口為「日誌與維修」頁面中的「維修工作區」。

[截圖：「日誌與維修」頁面切到「維修工作區」，包含「維修工作區」與「新增維修」]

## 查看維修列表

### 適用情境

當你要查看目前物業或特定房間的維修單，並依狀態或指派人員縮小範圍時，使用此操作。

[截圖：「維修工作區」，包含「維修狀態篩選」與「清除篩選」]

### 操作步驟

1. 從側邊選單進入「日誌與維修」。
2. 在「日誌維修切換」中選擇「維修工作區」。
3. 使用「維修狀態篩選」選擇「待派工」、「已派工」、「處理中」、「已完成」或「已取消」。
4. 需要時使用「指派人員篩選」。
5. 查看表格中的「狀態」、「房間」、「維修事項」、「指派」與「更新時間」。
6. 若要回到完整列表，點選「清除篩選」。

### 完成後會看到什麼

畫面會顯示符合條件的維修單。若沒有資料，會看到「目前沒有維修單。」或「此房間目前沒有維修單。」

### 注意事項

- 若畫面顯示「已套用房間篩選」，列表只會顯示該房間的維修單。
- 若「成員選單暫時無法載入」，仍可查看維修列表，但指派篩選或派工可能需要稍後再試。
- 表格分頁會顯示總筆數與目前頁次。

### 常見問題

**Q：我套用篩選後看不到資料，是資料不見了嗎？**  
A：不一定。請先點選「清除篩選」或「重新整理」確認完整列表。

**Q：為什麼指派人員選單沒有載入？**  
A：畫面可能顯示「成員選單暫時無法載入」，請稍後再試；維修列表仍可查看。

## 建立維修單

### 適用情境

當房間發生需要追蹤的維修問題，且你要建立一筆新的維修單時，使用此操作。

[截圖：「新增維修單」，包含「房間（必填）」與「建立後可立即上傳附件」]

### 操作步驟

1. 進入「日誌與維修」並切到「維修工作區」。
2. 點選「新增維修」。
3. 在「新增維修單」抽屜中確認「物業」。
4. 選擇「房間（必填）」。
5. 填寫「維修標題（必填）」。
6. 填寫「問題描述（必填）」。
7. 點選「儲存並重新載入」。

### 完成後會看到什麼

儲存成功後，畫面會顯示「維修單建立已完成，正在更新資料。」並在抽屜中保留該維修單；若成功取得維修單資料，會出現「維修附件」上傳入口。

### 注意事項

- 「房間（必填）」、「維修標題（必填）」與「問題描述（必填）」都必須完成。
- 若從單一房間脈絡進入，「房間（必填）」可能已套用且不能修改。
- 建立後才會顯示「維修附件」，因此附件需在儲存成功後上傳。
- 業主角色目前不能建立維修單。

### 常見問題

**Q：為什麼一開始不能上傳附件？**  
A：畫面提示「建立後可立即上傳附件」，代表需要先儲存維修單，再上傳施工照片或其他文件。

**Q：我不能選房間怎麼辦？**  
A：如果你是從特定房間進入，畫面可能已套用房間篩選；請先確認頁面上的房間提示。

## 查看維修詳情

### 適用情境

當你要查看單筆維修單的完整資訊、狀態、時間與附件時，使用此操作。

[截圖：「維修詳情」，包含「狀態」與「維修附件」]

### 操作步驟

1. 在「維修工作區」找到要查看的維修單。
2. 點選該列的「詳情」。
3. 在「維修詳情」抽屜中查看「狀態」、「物業」、「房間」、「標題」與「描述」。
4. 查看「建立人」、「指派人員」、「建立時間」、「派工時間」、「完成時間」與「更新時間」。
5. 若有附件，查看「維修附件」區塊。
6. 查看下方可用操作，例如「編輯」、「派工」、「開始處理」、「完成」或「取消」。

### 完成後會看到什麼

右側抽屜會顯示維修單完整資訊。若系統正在同步，會看到「正在同步最新維修資料...」。

### 注意事項

- 「維修詳情」中的可用按鈕會依目前狀態顯示。
- 若資料已變更，請依畫面提示重新載入或重新開啟詳情。
- 附件區塊只會在維修單已有系統編號時出現。

### 常見問題

**Q：為什麼有些維修單沒有「完成」按鈕？**  
A：目前只有「處理中」狀態的維修單會顯示「完成」操作。

**Q：詳情抽屜顯示載入中很久怎麼辦？**  
A：可關閉後重新點選「詳情」，或使用頁面上的「重新整理」。

## 編輯維修單

### 適用情境

當維修標題或問題描述需要修正時，使用此操作。

[截圖：「編輯維修單」，包含「維修標題（必填）」與「維修附件」]

### 操作步驟

1. 在維修列表或「維修詳情」中點選「編輯」。
2. 在「編輯維修單」抽屜中確認目前內容。
3. 修改「維修標題（必填）」。
4. 修改「問題描述（必填）」。
5. 需要時在「維修附件」區塊補充附件。
6. 點選「儲存並重新載入」。

### 完成後會看到什麼

儲存成功後，畫面會顯示「維修單更新已完成，正在更新資料。」列表與詳情會重新讀取最新資料。

### 注意事項

- 編輯既有維修單時，「房間（必填）」目前不可修改。
- 「維修標題（必填）」與「問題描述（必填）」不能留空。
- 附件可在編輯抽屜中的「維修附件」區塊處理。

### 常見問題

**Q：可以把維修單改到另一個房間嗎？**  
A：目前編輯畫面中的房間欄位不可修改，請以畫面可操作範圍為準。

## 指派維修

### 適用情境

當維修單狀態為「待派工」，需要指定工作室成員處理時，使用此操作。

[截圖：「指派維修」，包含「工作室成員（必填）」與「指派」]

### 操作步驟

1. 在維修列表找到狀態為「待派工」的維修單。
2. 點選「派工」。
3. 在「指派維修」視窗中選擇「工作室成員（必填）」。
4. 點選「指派」。
5. 等待列表與詳情重新載入。

### 完成後會看到什麼

畫面會顯示「維修派工已完成，正在更新資料。」該筆維修單狀態會更新，並顯示指派人員。

### 注意事項

- 只有「待派工」狀態會顯示「派工」。
- 若成員選單暫時無法載入，請稍後重試。
- 若狀態已被其他人更新，畫面會要求重新載入確認最新狀態。

### 常見問題

**Q：我找不到「派工」按鈕。**  
A：請確認該維修單目前是否為「待派工」狀態。

## 更新維修狀態

### 適用情境

當維修單已派工、正在處理，或需要取消時，使用此操作更新狀態。

[截圖：「取消維修」，包含「確認取消此維修？」與「取消原因」]

### 操作步驟

1. 在維修列表或「維修詳情」找到要處理的維修單。
2. 若狀態為「已派工」，點選「開始處理」。
3. 若狀態為「處理中」，點選「完成」。
4. 若要取消可處理的維修單，點選「取消」。
5. 若開啟「取消維修」，可填寫「取消原因」，再點選「取消維修」。
6. 等待畫面重新讀取維修與房間狀態。

### 完成後會看到什麼

狀態更新成功後，畫面會顯示成功訊息，並重新載入維修列表與詳情。取消維修時，畫面會提示「取消後會重新讀取維修與房間狀態；房間狀態由系統工作流程判斷。」

### 注意事項

- 「開始處理」只出現在「已派工」狀態。
- 「完成」只出現在「處理中」狀態。
- 「取消」會開啟確認視窗，不是直接取消。
- 若狀態已更新，請依畫面提示重新載入後再操作。

### 常見問題

**Q：取消原因一定要填嗎？**  
A：目前「取消原因」欄位顯示可留空。

**Q：完成或取消後房間狀態會怎樣？**  
A：畫面文字顯示會重新讀取維修與房間狀態，實際房間狀態由系統工作流程判斷。

## 上傳維修照片或附件

### 適用情境

當你要補充施工前、施工後、其他照片或 PDF 文件到維修單時，使用此操作。

[截圖：「維修附件」，包含「選擇施工照片」與「選擇其他文件」]

### 操作步驟

1. 開啟「維修詳情」或「編輯維修單」，確認畫面出現「維修附件」。
2. 若要上傳照片，點選「選擇施工照片」。
3. 若要上傳文件，點選「選擇其他文件」。
4. 選擇檔案後，確認畫面顯示「已選擇施工照片」或「已選擇其他文件」。
5. 上傳施工照片時，選擇「施工照片階段」，並視需要調整「施工照片排序」。
6. 點選「確認上傳施工照片」或「確認上傳其他文件」。

### 完成後會看到什麼

上傳成功後，畫面會顯示「附件已上傳並完成登記。」並在「已上傳附件」清單中看到檔名、建立時間，施工照片還會顯示「施工前」、「施工後」或「其他照片」標籤。

### 注意事項

- 施工照片支援 JPG、PNG、HEIC，並需標示階段與排序。
- 其他文件僅支援 PDF。
- 單一檔案大小上限為 20MB。
- 已上傳附件可依檔案類型「預覽」或「下載」，也可點選「刪除」並確認刪除。

### 常見問題

**Q：為什麼 PDF 不能用「選擇施工照片」上傳？**  
A：畫面規則顯示施工照片只支援 JPG、PNG 或 HEIC；PDF 請使用「選擇其他文件」。

**Q：HEIC 照片可以預覽嗎？**  
A：目前可預覽的圖片以畫面上的「預覽」按鈕為準；若顯示「下載」，請使用下載查看。

## 完成維修

### 適用情境

當維修單已處理完成，且需要在完成前補齊施工照片或完工文件時，使用此操作。

[截圖：「完成維修」，包含「完工前可先補齊施工照片」與「確認完成」]

### 操作步驟

1. 在維修列表或「維修詳情」找到狀態為「處理中」的維修單。
2. 點選「完成」。
3. 在「完成維修」視窗中閱讀「完工前可先補齊施工照片」提示。
4. 若有施工後照片或完工文件，先在「維修附件」區塊上傳。
5. 確認附件處理完成後，點選「確認完成」。
6. 等待維修與房間狀態重新讀取。

### 完成後會看到什麼

畫面會顯示「維修完成已完成，正在更新資料。」維修列表與詳情會重新載入。完成時間會在「維修詳情」中顯示。

### 注意事項

- 「確認完成」在附件上傳或刪除進行中會暫時不可操作。
- 完成後會重新讀取維修與房間狀態；房間狀態由系統工作流程判斷。
- 若完成失敗，請依「無法完成維修」提示處理。

### 常見問題

**Q：完成前一定要上傳照片嗎？**  
A：畫面提示「若有施工後照片或完工文件，請先在下方上傳」；是否必須上傳需以實際作業規範為準。

**Q：完成維修後房間會自動恢復可用嗎？**  
A：目前畫面只能確認會重新讀取維修與房間狀態；實際房間狀態由系統工作流程判斷。
