# 01 登入與導覽

本章適用於所有已開通 STDS 管理後台的使用者，說明如何登入、登出、確認目前物業、使用選單，以及判讀常見頁面狀態。

## 登入系統

### 適用情境

當你要開始使用 STDS 管理後台，或畫面提示「登入狀態已失效」時，使用此操作重新進入系統。

### 操作步驟

[截圖：「登入頁」，包含「STDS 管理後台」、「電子信箱」]

1. 開啟 STDS 管理後台登入頁。
2. 確認畫面標題為「STDS 管理後台」。
3. 在「電子信箱」欄位輸入已開通的後台帳號。
4. 在「密碼」欄位輸入密碼。
5. 點選「登入」。
6. 若畫面顯示「登入失敗」，依提示確認電子信箱與密碼後再試一次。

### 完成後會看到什麼

登入成功後，會進入後台頁面。頁面會顯示「目前物業」、目前使用者、角色標籤，以及主要工作選單。

### 注意事項

- 只能使用已開通的後台帳號登入。
- 若看到「帳號尚未開通」，請聯絡管理員確認後台使用權限。
- 若看到「登入設定尚未完成」或「登入同步失敗」，請先依畫面提示重試或聯絡管理員。

### 常見問題

**Q：我看到「電子信箱或密碼不正確，請確認後再試一次。」怎麼辦？**  
A：請重新確認電子信箱與密碼；若仍無法登入，請聯絡管理員協助確認帳號狀態。

**Q：畫面提示「登入狀態已失效」是什麼意思？**  
A：請重新登入後繼續使用。

## 登出系統

### 適用情境

當你完成後台作業、要交接電腦，或需要改用另一個帳號登入時，使用此操作離開目前登入狀態。

### 操作步驟

[截圖：「工作台頁首」，包含「目前物業」、「角色標籤」]

1. 確認目前位於 STDS 管理後台內頁。
2. 在頁首右側找到目前使用者資訊與角色標籤。
3. 點選頁首右側的登出圖示按鈕。
4. 等待系統離開目前登入狀態。
5. 若需要再次使用，回到登入頁重新輸入「電子信箱」與「密碼」。

### 完成後會看到什麼

系統會離開目前帳號的登入狀態。再次進入受保護的後台頁面時，會回到登入流程。

### 注意事項

- 共用電腦使用完畢後，請務必登出。
- 若只是要查看個人資料，請使用頁首的「我的帳號」按鈕，不需要登出。

### 常見問題

**Q：我找不到登出按鈕怎麼辦？**  
A：請先確認你已登入後台內頁；登出圖示按鈕在頁首右側的帳號資訊旁。行動版畫面仍位於頁首右側按鈕區。

## 切換或確認目前物業

### 適用情境

當你要確認目前正在處理哪一個物業，或要在不同物業之間切換日常作業範圍時，使用此操作。

### 操作步驟

[截圖：「側邊欄目前物業」，包含「目前物業」、「選擇物業」]

1. 在頁首查看「目前物業」標籤與物業名稱。
2. 在側邊欄找到「目前物業」區塊。
3. 使用「選擇物業」欄位打開可選物業清單。
4. 選擇要切換的物業。
5. 等待頁面切換到新的目前物業。
6. 再次確認頁首與側邊欄顯示的物業名稱是否正確。

### 完成後會看到什麼

頁首會更新「目前物業」名稱。若你原本位於房間管理、租客與租約、退租審核、帳單與抄表、日誌與維修或報表中心，系統會嘗試切換到新物業下相同的工作區。

### 注意事項

- 若顯示「尚未選擇物業」，代表目前沒有明確的物業範圍。
- 若顯示「載入物業中」，請等待物業清單載入完成。
- 若顯示「物業清單暫時無法讀取。」，請稍後重試或回到工作台確認。
- 切換物業時，特定房間、租客、租約或明細頁可能會回到新物業的對應列表頁。

### 常見問題

**Q：為什麼我看不到某個物業？**  
A：可見物業會依目前帳號與角色顯示；請聯絡管理員確認你的物業範圍。

**Q：切換物業後，為什麼沒有停在同一筆資料？**  
A：單筆房間、租客、租約或明細通常只屬於原物業；切換物業後，系統可能改回新物業的列表或工作台。

## 使用側邊選單

### 適用情境

當你要從目前頁面前往工作台、日常作業或管理功能時，使用側邊選單導覽。

### 操作步驟

[截圖：「側邊選單」，包含「日常作業」、「管理」]

1. 在桌面版畫面左側找到「STDS 管理後台」側邊欄。
2. 先確認「目前物業」是否為你要處理的物業。
3. 選擇「工作台」查看整體摘要。
4. 在「日常作業」下選擇「物業工作台」、「房間管理」、「租客與租約」、「退租審核」、「帳單與抄表」、「日誌與維修」或「報表中心」。
5. 在「管理」下選擇「我的帳號」、「物業管理」、「品牌內容」或「成員與權限」。
6. 行動版畫面請先點選「開啟主選單」，再選擇要前往的項目。

### 完成後會看到什麼

主內容區會切換到你選擇的頁面。側邊選單會保留目前後台導覽，頁首仍會顯示目前物業與使用者資訊。

### 注意事項

- 「品牌內容」只會在部分管理角色顯示。
- 「成員與權限」不會對業主角色顯示。
- 若尚未選擇物業，部分日常作業入口可能無法使用。
- 行動版主選單會以抽屜方式打開，選擇項目後會關閉。

### 常見問題

**Q：我看不到「品牌內容」或「成員與權限」是系統錯誤嗎？**  
A：不一定。這些入口會依角色顯示，請先確認目前角色標籤。

**Q：我應該從「工作台」還是「物業工作台」開始？**  
A：「工作台」查看整體摘要；「物業工作台」查看目前物業範圍內的作業入口與資訊。

## 看懂頁面狀態

### 適用情境

當頁面沒有立即顯示資料、顯示錯誤、無資料、權限不足或找不到頁面時，使用此操作判斷下一步。

### 操作步驟

[截圖：「頁面狀態」，包含「頁面載入失敗」、「回工作台」]

1. 先看頁面主標題或狀態標題，例如「載入中」、「頁面載入失敗」或「沒有權限查看此頁」。
2. 若顯示「載入中」，等待頁面完成準備。
3. 若顯示「目前沒有資料」或類似無資料提示，閱讀說明文字確認是否真的沒有可顯示內容。
4. 若顯示「頁面載入失敗」，可點選「重試」或「回工作台」。
5. 若顯示「沒有權限查看此頁」，請點選「回工作台」，並確認目前角色與目前物業。
6. 若顯示「找不到頁面或資料」，請回到工作台重新選擇入口。

### 完成後會看到什麼

依狀態不同，你可能會看到頁面內容成功載入、空資料說明、重試結果，或回到「工作台」重新選擇功能。

### 注意事項

- 「載入中」代表系統正在準備頁面內容，通常不需要立即重整。
- 「目前沒有資料」不一定是錯誤，可能代表目前範圍內沒有符合條件的資料。
- 「沒有權限查看此頁」與角色或物業範圍有關，請勿改用其他未授權方式處理。
- 「找不到頁面或資料」通常需要回到工作台或列表頁重新選擇。

### 常見問題

**Q：看到「頁面載入失敗」時要先做什麼？**  
A：先點選「重試」；如果仍失敗，請回工作台後再進入同一頁。

**Q：看到「目前沒有資料」代表我操作錯了嗎？**  
A：不一定。請先閱讀畫面說明，確認目前物業、篩選條件與角色範圍是否正確。

**Q：看到「沒有權限查看此頁」怎麼辦？**  
A：請回工作台，確認目前帳號角色與物業範圍；若仍需要使用該功能，請聯絡管理員。
