# STDS 管理後台使用者手冊

更新日期：2026-05-17

本手冊提供 STDS 管理後台的日常操作說明，協助使用者理解登入、導覽、物業切換、各工作區入口，以及常見頁面狀態。內容以目前系統畫面可見文字為準；尚未在目前畫面確認的內容不列入手冊。

## 手冊目的

- 協助非工程使用者快速找到對應工作區。
- 說明每個工作流的適用情境、操作步驟、完成後畫面與注意事項。
- 讓使用者遇到載入、無資料、錯誤或權限限制時，知道下一步該怎麼判斷。
- 作為內部營運操作的使用說明，依目前可驗收畫面維護。

## 適用角色

本手冊適用於已開通 STDS 管理後台的使用者。畫面上的角色可能顯示為：

- 系統管理員
- 營運管理
- 工作室成員
- 業主

不同角色可看到的選單與可執行的動作可能不同。若看不到某個入口，請先確認目前角色與目前物業是否符合該作業需求。

## 系統基本導覽

登入後，畫面會進入「STDS 管理後台」。左側或行動版主選單會顯示主要工作區，頁首會顯示「目前物業」、目前登入使用者與角色。

[截圖：「工作台總覽」，包含「目前物業」、「工作台」]

目前已確認的主要選單包含：

- 工作台
- 日常作業
- 物業工作台
- 房間管理
- 租客與租約
- 退租審核
- 帳單與抄表
- 日誌與維修
- 報表中心
- 管理
- 我的帳號
- 物業管理
- 品牌內容
- 成員與權限

「品牌內容」目前只會在部分管理角色顯示。「成員與權限」不會對業主角色顯示。

## 閱讀方式

建議先閱讀「01 登入與導覽」，確認登入、登出、切換目前物業與看懂頁面狀態的方式。之後可依日常工作直接跳到對應章節，例如房間管理、租客與租約、帳單與抄表、日誌與維修或報表中心。

每個操作章節都會使用相同格式：

- 適用情境
- 操作步驟
- 完成後會看到什麼
- 注意事項
- 常見問題

## 文件維護原則

- 只使用系統目前可見或已確認的畫面文字。
- 不放真實個資、真實帳號、真實租客姓名、真實地址、敏感金額或截圖。
- 若需要補圖，先使用 `[截圖：「畫面名稱」，包含「關鍵 UI 1」、「關鍵 UI 2」]` 標記。
- 若畫面名稱、按鈕或流程尚未確認，不列入手冊內容。
