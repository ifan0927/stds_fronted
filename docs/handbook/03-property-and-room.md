# 物業與房間

本篇說明如何在 STDS 管理後台查看與維護「物業管理」、「物業工作台」與「房間清冊」。適用於需要管理物業主檔、查看房間狀態、建立房間、編輯房間資料，以及判斷房間是否可刪除或設為維修的後台使用者。

## 查看物業清單
### 適用情境
需要查看目前帳號可存取的物業、基本聯絡資料與出租摘要。

### 操作步驟
[截圖：「物業管理」，包含「物業管理」、「物業列表」]

1. 在側邊欄選擇「物業管理」。
2. 確認頁面標題為「物業管理」。
3. 查看提示「列表依授權範圍顯示」。
4. 在「物業列表」查看欄位：「物業」、「地址 / 聯絡」、「出租概況」、「預設電費」、「操作」。
5. 如需更新列表，按「重新整理」。

### 完成後會看到什麼
會看到目前帳號可查看的物業列表。每筆物業可顯示名稱、副標、地址、聯絡資料、出租率、房間數、預設電費與操作按鈕。

### 注意事項
- 物業列表依目前帳號的角色與物業指派顯示。
- 若沒有可顯示資料，畫面會顯示「目前沒有可顯示的物業。」。
- 每筆物業的「操作」欄可依權限顯示「進入工作台」、「附件」、「編輯」與「刪除」。

### 常見問題
- Q：為什麼看不到某個物業？
  A：可見物業由系統依角色與物業指派決定。

## 查看物業工作台
### 適用情境
需要查看單一物業的摘要、基本資料、房間狀態與工作入口。

### 操作步驟
[截圖：「物業工作台」，包含「物業基本資料」、「工作入口」]

1. 進入「物業管理」。
2. 在目標物業的「操作」欄按「進入工作台」。
3. 確認頁面上方顯示目前物業名稱。
4. 查看上方卡片：「房間總數」、「出租率」、「本月預期租金」、「逾期帳單」。
5. 查看「物業基本資料」、「房間狀態」、「工作入口」與「近期日誌」。
6. 如需回到列表，按「回物業列表」。

### 完成後會看到什麼
會看到該物業的摘要卡片、物業基本資料、房間狀態表、工作入口與近期日誌。

### 注意事項
- 「工作入口」可前往「房間管理」、「租客與租約」、「抄表與帳單」、「日誌與維修」、「報表中心」。
- 「房間狀態」只顯示房間名稱與狀態；完整房間資料請進入「房間管理」。
- 若畫面顯示「目前沒有營運摘要」，代表目前只顯示物業基本資料與可用區塊。

### 常見問題
- Q：物業工作台和物業列表有什麼差別？
  A：物業列表用來比較多個物業；物業工作台用來查看單一物業的摘要與入口。
- Q：物業工作台可以直接刪除物業嗎？
  A：有權限時會看到「刪除」；若物業仍有房間或其他關聯資料，畫面可能顯示無法刪除。

## 新增物業
### 適用情境
需要建立新的物業主檔，並選擇或新增業主。

### 操作步驟
[截圖：「新增物業」，包含「物業基本資料」、「建立物業」]

1. 進入「物業管理」。
2. 按「新增物業」。
3. 在「物業基本資料」填寫「內部物業名稱（必填）」、「地址（必填）」、「電費單價（必填）」、「預設電費週期（必填）」與其他需要的欄位。
4. 選擇「業主（必填）」；若有權限，可在選單中按「新增業主」。
5. 確認資料後按「建立物業」。
6. 若不建立，按「取消」。

### 完成後會看到什麼
建立成功後會回到新物業的頁面。若資料不完整，畫面會在對應欄位或頁面上顯示需要修正的提示。

### 注意事項
- 必填欄位未填時無法建立物業。
- 「品牌頁公開名稱」可留空；畫面說明會提示留空時建立物業會沿用內部物業名稱。
- 「新增業主」是否可用，會依目前角色決定。

### 常見問題
- Q：一定要先選業主嗎？
  A：新增物業畫面目前顯示「業主（必填）」，需先選擇業主。
- Q：新增物業會同時建立房間嗎？
  A：不會。新增物業頁只維護物業主檔，房間需在「房間清冊」新增。

## 編輯物業
### 適用情境
需要調整物業名稱、地址、聯絡資料、備註、設施或其他物業主檔資料。

### 操作步驟
[截圖：「編輯物業」，包含「編輯物業」、「儲存變更」]

1. 從「物業管理」按目標物業的「編輯」，或在物業工作台按「編輯主檔」。
2. 確認頁面標題為「編輯物業」。
3. 在「物業基本資料」修改需要更新的欄位。
4. 若看到「目前角色不能修改電費預設值」，請只修改允許的欄位。
5. 確認後按「儲存變更」。
6. 若不儲存，按「取消」。

### 完成後會看到什麼
儲存成功後會回到該物業頁。若儲存失敗，畫面會顯示「更新物業失敗」或欄位提示。

### 注意事項
- 「內部物業名稱（必填）」、「地址（必填）」、「電費單價（必填）」與「預設電費週期（必填）」是目前畫面可確認的必填欄位。
- 工作室成員不能修改電費單價與預設電費週期時，畫面會顯示提示。
- 若目前角色不能異動物業主檔，畫面會提示「目前角色不能異動物業主檔」。

### 常見問題
- Q：為什麼有些欄位不能改？
  A：畫面會依目前角色限制部分欄位，請依提示操作。
- Q：編輯後會自動回到哪裡？
  A：儲存成功後會回到該物業頁。

## 刪除物業
### 適用情境
需要將不再使用的物業從一般管理列表移除。

### 操作步驟
[截圖：「確認刪除物業」，包含「確認刪除物業」、「刪除物業」]

1. 在「物業管理」找到目標物業，或進入該物業工作台。
2. 按「刪除」。
3. 在「確認刪除物業」視窗確認物業名稱。
4. 若確定要刪除，按「刪除物業」。
5. 若不刪除，按「取消」。

### 完成後會看到什麼
刪除成功後，物業會從一般管理列表移除。若無法刪除，視窗會顯示「刪除物業失敗」。

### 注意事項
- 刪除物業需要較高權限；沒有權限時按鈕可能不可用。
- 若物業仍有房間或其他關聯資料，畫面可能顯示無法刪除。
- 刪除前請先確認房間與租約狀態。

### 常見問題
- Q：刪除物業失敗時怎麼辦？
  A：先確認該物業是否仍有房間或其他關聯資料，再重新判斷是否可刪除。
- Q：刪除後可以在一般管理列表看到嗎？
  A：刪除後此物業不會出現在一般管理列表。

## 查看房間清冊
### 適用情境
需要查看目前物業的房間狀態、基本資料與相鄰工作流入口。

### 操作步驟
[截圖：「房間清冊」，包含「房間清冊」、「新增房間」]

1. 進入目標物業工作台。
2. 在「工作入口」選擇「房間管理」，或從側邊欄選擇「房間管理」。
3. 確認頁面標題為「房間清冊」。
4. 在表格查看欄位：「房間」、「狀態」、「坪數 / 樓層 / 區域」、「預設租金」、「備註」、「操作」。
5. 視需要使用「房況」、「每頁筆數」或「清除篩選」調整目前清冊顯示。
6. 如需更新列表，按「重新整理」。

### 完成後會看到什麼
會看到目前物業的房間列表與每筆房間的操作按鈕。沒有資料時會顯示「目前沒有可顯示的房間。」或「此房況目前沒有房間。」。

### 注意事項
- 「搬入」只會在空房列上顯示。
- 「查看」、「帳單」、「日誌維修」會帶你前往該房間相關工作頁。
- 若要回到單一物業頁，按「回物業工作台」。

### 常見問題
- Q：為什麼某些房間沒有「搬入」？
  A：目前畫面只在空房顯示「搬入」。
- Q：房況有哪些選項？
  A：目前可確認的選項是「全部房況」、「空房」、「出租中」、「維修中」。

## 新增房間
### 適用情境
需要在目前物業建立新的房間主檔。

### 操作步驟
[截圖：「新增房間」，包含「房間名稱」、「建立房間」]

1. 進入「房間清冊」。
2. 按「新增房間」。
3. 在「新增房間」頁填寫「房間名稱」。
4. 視需要填寫「房型」、「坪數」、「樓層」、「區域」、「預設租金」、「房內設施」、「備註」。
5. 確認後按「建立房間」。
6. 若不建立，按「取消」或「回房間清冊」。

### 完成後會看到什麼
建立成功後會前往新房間的詳情頁；若資料暫時不完整，可能回到房間清冊。

### 注意事項
- 「房間名稱」是目前畫面可確認的必填欄位。
- 新增房間頁只建立房間主檔；租客搬入、附件與維修流程會由各自頁面承接。
- 表單中的範例文字只是填寫提示，不代表真實資料。

### 常見問題
- Q：新增房間時可以一起搬入租客嗎？
  A：不行。新增房間頁只建立房間主檔，搬入需到租客與租約相關流程處理。
- Q：房內設施要怎麼填？
  A：目前畫面以文字欄位填寫，請依內部約定填入清楚描述。

## 查看與編輯房間
### 適用情境
需要查看房間主檔、房況、工作入口，或修改房間基本資料。

### 操作步驟
[截圖：「房間詳情」，包含「房間主檔」、「編輯」]

1. 進入「房間清冊」。
2. 在目標房間的「操作」欄按「查看」。
3. 在「房間主檔」查看欄位：「房間名稱」、「房況」、「房型」、「坪數」、「樓層」、「區域」、「預設租金」、「房內設施」、「備註」、「建立時間」、「更新時間」。
4. 若要修改，按「編輯」。

[截圖：「編輯房間」，包含「編輯房間」、「儲存」]

5. 在「編輯房間」視窗修改資料後按「儲存」。
6. 若不修改，按「取消」。

### 完成後會看到什麼
會看到房間詳情、工作入口與附件區塊。儲存成功後，房間資料會更新在目前頁面。

### 注意事項
- 房間頁的「工作入口」目前可前往「搬入租客」或「租客與租約」、「抄表與帳單」、「抄表歷史」、「日誌與維修」。
- 房間詳情頁的狀態會以「空房」、「出租中」或「維修中」呈現。
- 編輯房間只調整房間主檔，不會直接處理租約、帳單或完整維修流程。

### 常見問題
- Q：房間詳情頁可以查看附件嗎？
  A：目前房間詳情頁有附件區塊，是否可異動依畫面權限為準。
- Q：編輯房間後會離開頁面嗎？
  A：目前儲存成功後會留在房間詳情頁並更新顯示資料。

## 將房間設為維修
### 適用情境
需要把空房標記為維修中，並建立維修入口。

### 操作步驟
[截圖：「將房間設為維修」，包含「維修標題」、「建立維修入口」]

1. 進入目標房間詳情頁。
2. 查看頁首的房況標籤，確認房間是「空房」。
3. 按「設為維修」。
4. 在視窗填寫「維修標題」與「問題描述」。
5. 確認後按「建立維修入口」。
6. 若不建立，按「取消」。

### 完成後會看到什麼
成功後，畫面會提示「已建立維修入口，房間狀態已更新。」並前往日誌與維修相關頁。

### 注意事項
- 出租中或維修中的房間不能在此直接設定維修，按鈕會不可用。
- 視窗會提示「只建立維修入口」；完整派工、進度、完成與取消會在日誌與維修頁面處理。

### 常見問題
- Q：為什麼「設為維修」是灰色不能按？
  A：出租中或維修中的房間不能在此直接設定維修。

## 刪除房間
### 適用情境
需要判斷空房是否可以從一般管理清冊移除。

### 操作步驟
[截圖：「刪除房間」，包含「刪除房間」、「刪除」]

1. 進入目標房間詳情頁。
2. 查看頁首的房況標籤，確認房間是「空房」。
3. 按「刪除」。
4. 在「刪除房間」視窗確認提示內容。
5. 若確定刪除，按「刪除」。
6. 若不刪除，按「取消」。

### 完成後會看到什麼
刪除成功後，會回到房間清冊或物業相關頁。若無法刪除，視窗會顯示「無法刪除房間」。

### 注意事項
- 出租中或維修中的房間不能在此直接刪除，按鈕會不可用。
- 「刪除房間」視窗會提示：出租中或維修中的房間會由系統拒絕。
- 本手冊只說明目前畫面可確認的「刪除」操作。

### 常見問題
- Q：為什麼「刪除」是灰色不能按？
  A：出租中或維修中的房間不能在此直接刪除。
