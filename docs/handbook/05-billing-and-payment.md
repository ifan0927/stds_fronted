# 帳單與收款操作手冊

適用角色：需要查看租金與電費帳單、處理抄表、確認收款、開啟收據，以及理解帳單狀態的後台使用者。實際可執行的動作會依畫面開放狀態而不同；若目前只能查看，畫面會停用收款或抄表動作。

## 查看帳單處理清單
### 適用情境
需要針對單一房間或租約查看租金、電費帳單，並從清單進入詳情、抄表、收款或收據時使用。

### 操作步驟
[截圖：「帳單處理」，包含「選擇房間或租約」、「帳單狀態」]

1. 從左側選單進入「帳單與抄表」。
2. 確認停留在「帳單處理」分頁。
3. 在「選擇房間或租約」搜尋並選擇要處理的房間、租客或租約。
4. 使用「帳單狀態」篩選「全部狀態」、「待抄表」、「待收款」、「逾期」、「已付款」、「已作廢」或「已沖銷」。
5. 切換「電費帳單」或「租金帳單」分頁。
6. 查看表格欄位「帳單」、「週期 / 到期」、「金額」、「狀態」與「動作」。
7. 需要更新時，按「重新整理帳單」。

### 完成後會看到什麼
清單會顯示所選租約的帳單；每筆帳單會依狀態顯示「詳情」、「抄表」、「收款」或「收據」等可用動作。

### 注意事項
- 帳單處理會聚焦在單一租約；未選擇房間或租約時不會顯示帳單清單。
- 「收款」只會在可收款的帳單上開放。
- 「收據」只會在已付款帳單上開放。

### 常見問題
**為什麼畫面顯示請先選擇房間或租約？**
因為帳單處理需要先聚焦在單一租約，請先使用上方搜尋選單。

## 處理全物業抄表
### 適用情境
已拍完整棟電表，需要連續錄入待抄表帳單時使用。

### 操作步驟
[截圖：「全物業抄表工作佇列」，包含「待處理」、「抄表」]

1. 從「帳單與抄表」切換到「全物業抄表」分頁。
2. 查看「全物業抄表工作佇列」。
3. 確認表格欄位「房間 / 租客」、「帳單週期」、「上期度數」、「狀態」與「動作」。
4. 找到狀態為「待抄表」的資料列，按「抄表」。

[截圖：「送出抄表」，包含「本期電表度數（必填）」、「送出抄表」]

5. 在「送出抄表」側欄確認房間、租客、帳單週期與上期度數。
6. 填寫「本期電表度數（必填）」。
7. 確認「金額由系統計算」提示後，按「送出抄表」。

### 完成後會看到什麼
畫面會顯示抄表已送出的提示，帳單狀態會重新讀取。

### 注意事項
- 清單以待抄表帳單為準，每列仍是單筆送出。
- 本期度數不可小於畫面顯示的上期度數。
- 「歷史」按鈕若停用，請使用頁首「查看電表歷史」或帳單詳情中的「查看此房間歷史」。

### 常見問題
**待抄表帳單可以直接收款嗎？**
不行；請先完成抄表，讓帳單進入可收款狀態。

## 查看帳單詳情
### 適用情境
需要確認單筆帳單的類型、房間、租客、週期、到期日、狀態、金額、抄表與收款資訊時使用。

### 操作步驟
[截圖：「帳單詳情」，包含「帳單類型」、「狀態」]

1. 在「帳單處理」清單找到要查看的帳單。
2. 按該列「詳情」。
3. 在「帳單詳情」側欄查看帳單類型、物業、房間與租客。
4. 查看帳單週期、到期日、狀態與金額。
5. 若是電費帳單，確認上期度數、本期度數、電費單價與抄表時間。
6. 若已有收款資訊，查看收款方式、收款金額與收款時間。
7. 依帳單狀態使用側欄底部的「抄表」、「收款」、「開啟收據」或「查看此房間歷史」。

### 完成後會看到什麼
帳單詳情會停留在側欄中；若狀態可操作，側欄底部會顯示相應按鈕。

### 注意事項
- 「待抄表」帳單會提示需送出本期電表度數。
- 「待收款」與「逾期」帳單可確認完整收款。
- 「已付款」帳單可開啟系統收據。

### 常見問題
**詳情裡的收款金額可以手動改嗎？**
不行；收款金額固定使用帳單金額。

## 登錄收款
### 適用情境
租金或電費帳單已進入待收款或逾期狀態，需要確認完整收款時使用。

### 操作步驟
[截圖：「確認收款」，包含「收款方式（必填）」、「確認收款」]

1. 在「帳單處理」清單中找到狀態為「待收款」或「逾期」且已有金額的帳單。
2. 按該列「收款」，或先按「詳情」後在側欄底部按「收款」。
3. 在「確認收款」側欄確認帳單類型、房間、租客、帳單週期、目前狀態與收款金額。
4. 閱讀提示「收款方式為必填；收款金額固定使用帳單金額，不提供手動輸入」。
5. 在「收款方式（必填）」選擇「現金」、「匯款」或「其他」。
6. 按「確認收款」。

### 完成後會看到什麼
畫面會顯示「收款已確認，帳單狀態已重新讀取。」帳單狀態會更新，清單也會重新整理。

### 注意事項
- 收款時間不需要填寫，畫面提示會自動記錄。
- 只有待收款或逾期且已有金額的帳單可以收款。
- 如果目前只能查看，收款按鈕會停用。

### 常見問題
**可以部分收款嗎？**
目前畫面只支援確認完整收款；金額固定使用帳單金額。

**收款方式有哪些？**
目前畫面提供「現金」、「匯款」與「其他」。

## 開啟收據或查看付款紀錄
### 適用情境
帳單已付款後，需要開啟收據，或在帳單詳情確認收款方式、收款金額與收款時間時使用。

### 操作步驟
[截圖：「已付款帳單」，包含「已付款」、「收據」]

1. 在「帳單處理」清單選擇房間或租約。
2. 將「帳單狀態」調整為「已付款」，或直接找到狀態為「已付款」的帳單。
3. 按該列「收據」。
4. 若從「帳單詳情」側欄操作，按側欄底部「開啟收據」。
5. 若瀏覽器要求允許新視窗，依瀏覽器提示允許後重試。
6. 需要查看付款紀錄時，按「詳情」並查看收款方式、收款金額與收款時間。

### 完成後會看到什麼
系統會開啟收據預覽，並顯示「收據已開啟。」若未能開啟，畫面會顯示收據預覽相關提示。

### 注意事項
- 只有已付款帳單才能開啟收據。
- 收據內容與金額以帳單資料為準。
- 若收據預覽未開啟，可能是瀏覽器阻擋新視窗。

### 常見問題
**為什麼「收據」不能按？**
請確認帳單狀態是否為「已付款」。

## 處理收款失敗或資料被更新
### 適用情境
按下「確認收款」後，畫面顯示收款確認失敗、資料已被更新、帳單已完成收款、找不到帳單或沒有權限時使用。

### 操作步驟
[截圖：「收款提示」，包含「資料已被更新」、「重新整理帳單」]

1. 先閱讀畫面上方或側欄內的提示文字。
2. 若看到「資料已被更新」，按畫面提供的重新整理動作，或回到清單重新開啟該帳單。
3. 若看到「帳單已完成收款」，回到清單確認最新狀態是否已是「已付款」。
4. 若看到「找不到這張帳單」，重新整理帳單清單後再確認是否仍存在。
5. 若看到「沒有權限確認收款」，確認目前登入帳號是否具備該物業的操作權限。
6. 若是欄位提示，確認「收款方式（必填）」是否已選擇。

### 完成後會看到什麼
清單或詳情會重新讀取最新帳單狀態；若問題仍存在，畫面會保留對應錯誤或提示。

### 注意事項
- 發生資料更新提示時，請以重新整理後的清單為準，不要重複送出同一筆舊資料。
- 已付款帳單不需要再次確認收款。
- 沒有權限時，畫面不會代替權限審核，仍需依組織內部流程確認帳號權限。

### 常見問題
**看到收款確認失敗時，是否代表款項沒有收到？**
畫面只代表後台確認動作未完成；實際款項狀況請依你的營運收款紀錄另行確認。

## 理解帳單狀態
### 適用情境
需要判斷一張帳單現在能抄表、能收款、能開收據，或只能查看時使用。

### 操作步驟
[截圖：「帳單狀態」，包含「帳單狀態」、「狀態」]

1. 在「帳單與抄表」進入「帳單處理」。
2. 選擇房間或租約。
3. 查看表格中的「狀態」標籤。
4. 依狀態判斷可用動作：待抄表通常先處理抄表，待收款或逾期可收款，已付款可開收據。
5. 若狀態為已作廢或已沖銷，通常只能查看，不會開放一般收款。
6. 不確定時按「詳情」查看側欄提示。

### 完成後會看到什麼
你可以依畫面狀態判斷下一步應該抄表、收款、開收據，或只保留查看。

### 注意事項
- 「待抄表」表示金額可能尚待計算或更新。
- 「待收款」表示可確認完整收款。
- 「逾期」仍可確認完整收款。
- 「已付款」表示可開啟收據。

### 常見問題
**已作廢或已沖銷可以收款嗎？**
畫面通常只提供查看，不會開放一般收款。
