# 租客與租約操作手冊

適用角色：需要查看或維護租客、租約、入住、租約更換與退租流程的後台使用者。實際可執行的動作會依畫面開放狀態而不同；若按鈕停用，請依畫面提示處理。

## 查看租客與租約名冊
### 適用情境
需要確認目前物業的房間、租客、租約期間、租金、押金、下期租金與備註時使用。

### 操作步驟
[截圖：「租客與租約名冊」，包含「顯示空房」、「每頁筆數」]

1. 從左側選單進入「租客與租約」。
2. 確認頁面標題為「租客與租約名冊」。
3. 使用「顯示空房」切換「只看出租中」或「包含空房」。
4. 需要調整清單長度時，使用「每頁筆數」選擇 20、50 或 100 筆。
5. 查看表格欄位「房間」、「租客」、「租約期間」、「租金」、「押金」、「下期租金」、「備註」與「操作」。
6. 若要回到初始條件，按「清除篩選」。

### 完成後會看到什麼
畫面會列出符合篩選條件的租客與租約資料；頁尾會顯示目前筆數與頁數。

### 注意事項
- 頁首「顯示空房」按鈕會切換到包含空房的名冊視角。
- 名冊上方的「名冊內容」是「匯出房客名冊」使用的條件，可選「包含空房」或「只列出租中」。
- 若清單顯示「目前沒有出租中的租客租約資料。」，代表目前篩選條件下沒有出租中資料。
- 空房列才會出現「辦理入住」。

### 常見問題
**為什麼看不到空房？**
請把「顯示空房」調整為「包含空房」，或按頁首的「顯示空房」。

**表格中的金額可以直接改嗎？**
名冊表格只提供查看與入口；租金調整需進入「租約詳情」。

## 辦理空房入住並建立租約
### 適用情境
房間目前是空房，需要選擇既有租客或新增租客，並建立新的租約時使用。

### 操作步驟
[截圖：「空房入住」，包含「租客來源」、「租約條件」]

1. 在「租客與租約名冊」將「顯示空房」調整為「包含空房」。
2. 找到空房資料列，按「辦理入住」。
3. 在「空房入住」側欄確認「入住房間」資訊。
4. 在「租客來源」選擇「選擇既有租客」或「新增租客」。
5. 若選擇既有租客，使用「既有租客（必填）」下拉選單。
6. 若選擇新增租客，填寫「租客姓名（必填）」、「電子信箱（必填）」與畫面提供的其他資料。
7. 在「租約條件」填寫「租金（必填）」、「租約開始（必填）」、「租約結束（必填）」、「押金（必填）」與「起始電表讀數（必填）」。
8. 確認「租金週期」、「電費週期」與「租約備註」後，按「建立租約」。

### 完成後會看到什麼
畫面會提示入住已建立，名冊會重新整理，並進入該房間的「出租中房間總覽」。

### 注意事項
- 若既有租客清單暫時無法讀取，畫面會提示仍可改用新增租客完成入住。
- 若畫面顯示「房間狀態已變更，無法辦理入住」，請重新整理名冊後重新確認房間狀態。
- 文件與附件可於入住後到租客或租約詳情頁補齊。

### 常見問題
**起始電表讀數可以填 0 嗎？**
可以，畫面提示「0 也是有效值」。

## 查看出租中房間總覽
### 適用情境
需要從單一出租中房間進入租客、租約、收款、退租、租約更換、強制退租或抄表相關工作時使用。

### 操作步驟
[截圖：「出租中房間總覽」，包含「租金帳單摘要」、「工作入口」]

1. 在「租客與租約名冊」找到出租中的房間。
2. 按該列「房間總覽」。
3. 在「出租中房間總覽」側欄查看房間、租客、租約狀態、租約期間、租金、押金與備註。
4. 查看「租金帳單摘要」中的期別、到期日、金額與狀態。
5. 在「工作入口」選擇「租客詳情」、「租約詳情」、「收款與收據」、「退租結算」、「租約更換」、「強制退租」、「抄表與帳單」或「抄表歷史」。

### 完成後會看到什麼
你會停留在側欄總覽，或依選擇的工作入口前往對應頁面。

### 注意事項
- 若畫面顯示「房間狀態與租約資料不一致」，請先重新整理，不要把該房間視為空房。
- 若目前帳號不可執行租約更換或強制退租，工作入口會顯示不可操作。

### 常見問題
**為什麼有些入口不能按？**
通常是目前帳號不可執行該流程，請依畫面提示確認。

## 查看與編輯租客資料
### 適用情境
需要查看租客基本資料、聯絡人、租約歷史，或修改目前支援的租客欄位時使用。

### 操作步驟
[截圖：「租客詳情」，包含「租客資料」、「租約歷史」]

1. 從「出租中房間總覽」按「租客詳情」。
2. 確認頁面標題為租客名稱，並查看「租客資料」。
3. 查看「聯絡人」與「租約歷史」。
4. 需要修改時，按「編輯租客資料」。

[截圖：「編輯租客資料」，包含「新增聯絡人」、「儲存租客資料」]

5. 在「編輯租客資料」視窗中更新姓名、電子信箱、電話、生日、身分證字號、地址、職業或聯絡人。
6. 需要新增聯絡人時，按「新增聯絡人」；需要移除時，按「移除聯絡人」。
7. 按「儲存租客資料」。

### 完成後會看到什麼
畫面會顯示租客資料更新成功的提示，並重新讀取最新租客資料。

### 注意事項
- 目前畫面提示「租客備註未開放編輯」。
- 電子信箱若格式不正確，畫面會要求重新確認。
- 「租約歷史」中的「租約詳情」可前往該租約資料頁。

### 常見問題
**可以在租客詳情頁處理付款或收據嗎？**
不行；頁面說明租客備註、付款、收據與附件上傳由相關功能處理。

## 查看租約詳情與調整租金
### 適用情境
需要查看租約條件、租金帳單，或只調整租金金額時使用。

### 操作步驟
[截圖：「租約詳情」，包含「租約資料」、「租金帳單」]

1. 從「出租中房間總覽」按「租約詳情」，或從租客的「租約歷史」按「租約詳情」。
2. 在「租約詳情」頁查看「租約資料」。
3. 在「租金帳單」區塊使用「全部狀態」篩選待收款、逾期、已付款、已作廢或已沖銷。
4. 需要更新清單時，按「重新整理」。
5. 若只需修改租金，按「調整租金」。

[截圖：「調整租金」，包含「租金（必填）」、「送出租金調整」]

6. 在「調整租金」視窗填寫「租金（必填）」。
7. 確認「此調整可能影響後續租金帳單」提示後，按「送出租金調整」。

### 完成後會看到什麼
租約資料會重新讀取，租金帳單區塊也會更新到最新狀態。

### 注意事項
- 「調整租金」不修改租金週期、押金、付款或收據。
- 若需續約、週期變更或重發合約，請使用「租約更換」。
- 若目前帳號不能調整租金，按鈕會停用並顯示提示。

### 常見問題
**調整租金會等同續約嗎？**
不會。續約需使用「租約更換」。

## 辦理續約或租約更換
### 適用情境
需要續約、變更收款週期或重新建立合約，並讓新租約承接舊租約條件時使用。

### 操作步驟
[截圖：「租約更換」，包含「目前租約」、「更換內容」]

1. 從「出租中房間總覽」或「租約詳情」進入「租約更換」。
2. 確認頁面標題為「租約更換」，並查看「目前租約」。
3. 在「更換內容」選擇「更換原因（必填）」，例如「週期變更」、「續約」、「重發合約」或「其他例外」。
4. 填寫「生效日（必填）」、「新租約結束日（必填）」與「新租金（必填）」。
5. 選擇「租金週期（必填）」與「電費週期（必填）」。
6. 視需要填寫「新租約備註」。
7. 按「確認送出租約更換」。

### 完成後會看到什麼
畫面會顯示「租約更換已完成」，並提供「前往新租約」與「回租客與租約」。

### 注意事項
- 此流程不是退租、強制退租或押金結算。
- 「押金處理」目前顯示為「沿用舊租約押金」。
- 若生效日前仍有未結清帳單，畫面會要求先完成收款或處理帳單後再更換租約。

### 常見問題
**租約更換可以處理押金扣抵嗎？**
不行；畫面說明本流程固定押金沿用，不處理租金退款或押金扣抵。

## 辦理正常退租
### 適用情境
租約要走正常退租結算，需要產生退租試算並確認完成退租結算時使用。

### 操作步驟
[截圖：「退租結算試算」，包含「結算生效日 / 租約終止日（必填）」、「產生退租試算」]

1. 從「出租中房間總覽」或「租約詳情」按「退租結算」。
2. 在「退租結算試算」側欄確認物業、房間、租客、租約狀態、租期與押金。
3. 填寫「結算生效日 / 租約終止日（必填）」與「退租原因（必填）」。
4. 視需要填寫「實際搬出日 / 點交日」、「退租電表讀數」、清潔費、門禁卡遺失費、其他費用、人工未到期租金退款與備註。
5. 按「產生退租試算」。

[截圖：「退租結算試算結果」，包含「退租前還有待處理事項」、「確認完成退租結算」]

6. 檢查「退租結算試算結果」與待處理事項。
7. 若沒有待處理事項，按「確認完成退租結算」，再於確認視窗按「確認完成退租」。

### 完成後會看到什麼
畫面會顯示退租結算完成提示；若可開啟結算書，會開啟退租結算書預覽。

### 注意事項
- 正常退租需要進行中或已到期租約；已退租或強制退租資料請使用「退租審核與歷史」查看。
- 若有待處理帳單、抄表或押金狀態，需先處理後重新產生退租試算。
- 若結算生效日早於原租約結束日，請填寫人工未到期租金退款決策。

### 常見問題
**產生試算後還能改欄位嗎？**
可以，但修改後原試算會失效，需要重新產生退租試算。

## 辦理強制退租
### 適用情境
發生需要跳過正常退租試算的特殊情況，需建立強制退租記錄時使用。

### 操作步驟
[截圖：「強制退租」，包含「強制退租是獨立危險流程」、「押金處理（必填）」]

1. 從「出租中房間總覽」或「退租結算試算」按「強制退租」。
2. 在「強制退租」側欄確認警示「強制退租是獨立危險流程」。
3. 確認物業、房間、租客、租約狀態、租期與押金。
4. 填寫「強制退租日（必填）」。
5. 選擇「押金處理（必填）」：押金沖銷或保留押金。
6. 填寫「強制退租原因（必填）」。
7. 按「送出強制退租」，再於確認視窗按「確認強制退租」。

### 完成後會看到什麼
畫面會顯示「強制退租已建立」，並依畫面導向查看後續狀態。

### 注意事項
- 強制退租只從進行中租約發起。
- 此流程不使用正常退租試算，不會產生正常退租結算書。
- 若目前帳號不能執行強制退租，送出按鈕會停用或畫面會顯示提示。

### 常見問題
**按錯強制退租入口怎麼辦？**
可按「返回正常退租」回到正常退租流程。
