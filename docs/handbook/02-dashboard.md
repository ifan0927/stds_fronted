# 工作台

本篇說明如何使用 STDS 管理後台的「工作台」查看可見範圍內的營運摘要。適用於需要快速掌握出租狀態、帳務概況、物業摘要與近期日誌的後台使用者。

## 查看工作台
### 適用情境
登入後想先確認整體營運狀態，或需要從總覽頁判斷接下來要前往哪個工作頁。

### 操作步驟
[截圖：「工作台總覽」，包含「工作台」、「重新整理」]

1. 在側邊欄選擇「工作台」。
2. 確認頁面標題為「工作台」。
3. 查看頁首說明「查看授權範圍內的出租狀態、本月帳務摘要、物業概況與近期日誌。」。
4. 依序查看上方摘要卡片與下方區塊。
5. 若畫面資料看起來未更新，按「重新整理」。

### 完成後會看到什麼
會看到「房間總數」、「出租率」、「本月預期租金」、「逾期帳單」、「物業摘要」與「近期日誌」。

### 注意事項
- 工作台只顯示目前帳號可查看的範圍。
- 「重新整理」只會重新載入目前頁面的資料，不會修改任何內容。
- 工作台是摘要頁，異動資料需前往對應工作頁。

### 常見問題
- Q：為什麼工作台沒有任何資料？
  A：可能是目前可查看範圍內沒有可顯示的物業、房間、帳務或日誌摘要。
- Q：工作台上的數字可以直接編輯嗎？
  A：不行。工作台只提供摘要查看。

## 查看營運摘要
### 適用情境
需要快速確認房間規模、出租狀態、本月租金與逾期狀況。

### 操作步驟
[截圖：「工作台摘要卡片」，包含「房間總數」、「逾期帳單」]

1. 進入「工作台」。
2. 查看「房間總數」卡片，確認可見物業範圍內的房間數。
3. 查看「出租率」卡片，確認出租比例與「出租中」數量。
4. 查看「本月預期租金」卡片，比對「已收」金額。
5. 查看「逾期帳單」卡片，確認是否顯示「需追蹤」或「無逾期」。

### 完成後會看到什麼
會看到四個摘要卡片，分別呈現房間數、出租率、本月帳務摘要與逾期帳單數量。

### 注意事項
- 「逾期帳單」顯示「需追蹤」時，代表需要進一步到帳務相關頁面確認。
- 「出租率」與「本月預期租金」是摘要資訊，細節需到物業或帳務頁面查看。
- 若欄位顯示「未提供」，代表目前畫面沒有可顯示的該項資料。

### 常見問題
- Q：「需追蹤」代表已經完成處理了嗎？
  A：不是。「需追蹤」代表有逾期帳單，需要再進一步確認。
- Q：可以只看某一個物業的摘要嗎？
  A：可從「物業管理」進入單一物業的工作台查看。

## 查看物業摘要
### 適用情境
需要比較各物業的出租狀況與帳務摘要。

### 操作步驟
[截圖：「物業摘要」，包含「物業摘要」、「出租率」]

1. 進入「工作台」。
2. 在「物業摘要」區塊查看物業清單。
3. 依序查看表格欄位：「物業」、「出租率」、「房間狀態」、「預期租金」、「已收租金」、「逾期」。
4. 若表格沒有資料，確認畫面是否顯示「目前沒有可顯示的物業摘要。」。

### 完成後會看到什麼
「物業摘要」會列出各物業的出租與帳務概況，並在區塊右上角顯示目前列出的物業筆數。

### 注意事項
- 「房間狀態」會以「出租中」、「空房」、「維修」呈現各狀態數量。
- 「逾期」筆數可用來判斷哪個物業需要優先追蹤。

### 常見問題
- Q：物業摘要的「房間狀態」怎麼解讀？
  A：畫面會列出各狀態的房間數量，例如出租中、空房與維修。

## 查看近期日誌
### 適用情境
需要快速查看最近的營運紀錄與維修相關紀錄。

### 操作步驟
[截圖：「近期日誌」，包含「近期日誌」、「一般日誌」]

1. 進入「工作台」。
2. 查看「近期日誌」區塊。
3. 依序查看日誌類型、時間、內容與物業名稱。
4. 若沒有資料，確認畫面是否顯示「目前沒有近期日誌」。

### 完成後會看到什麼
「近期日誌」會顯示最近的日誌或維修紀錄；沒有資料時會顯示空狀態。

### 注意事項
- 「近期日誌」只提供快速瀏覽，不提供新增操作。
- 需要處理單一物業時，可改到「物業管理」或「物業工作台」查看細節。

### 常見問題
- Q：「近期日誌」可以在工作台新增嗎？
  A：不行。工作台只提供摘要查看。

## 從工作台判斷需要追蹤的資料
### 適用情境
需要從總覽頁先找出可能要處理的帳務、物業或營運紀錄。

### 操作步驟
[截圖：「工作台追蹤線索」，包含「需追蹤」、「逾期」]

1. 先查看「逾期帳單」卡片是否顯示「需追蹤」。
2. 在「物業摘要」中查看各物業的「逾期」筆數。
3. 比對「預期租金」與「已收租金」欄位。
4. 查看「近期日誌」是否有需要後續處理的紀錄。
5. 若需要處理單一物業，改到「物業管理」或「物業工作台」查看細節。

### 完成後會看到什麼
可以初步判斷哪些物業或帳務資料需要優先追蹤，但工作台本身不會直接完成後續處理。

### 注意事項
- 目前工作台可確認的追蹤提示是「逾期帳單」的「需追蹤」與物業摘要中的「逾期」筆數。
- 若沒有看到獨立的待處理事項清單，不要把工作台摘要視為完整待辦清單。

### 常見問題
- Q：看到逾期後要在哪裡處理？
  A：請前往對應物業的帳務相關頁面確認後續作業。
