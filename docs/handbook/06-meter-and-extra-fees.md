# 06 抄表與額外費用

本章適用於需要處理電表讀數、查看電費帳單、確認帳單狀態，以及記錄營運費用的使用者。已確認的主要入口為「帳單與抄表」；費用日誌目前可在「日誌與維修」的「營運日誌」中看到相關欄位。

[截圖：「帳單與抄表」頁面，包含「帳單處理」與「全物業抄表」頁籤]

## 查看待抄表帳單

### 適用情境

當你已完成現場抄表，準備把整個物業的待抄表電費帳單逐筆送出時，使用此操作。

[截圖：「全物業抄表工作佇列」，包含「待處理」與「抄表」]

### 操作步驟

1. 從側邊選單進入「帳單與抄表」。
2. 確認頁面標題為「帳單與抄表」。
3. 點選「全物業抄表」頁籤。
4. 查看「全物業抄表工作佇列」。
5. 在表格中確認「房間 / 租客」、「帳單週期」、「上期度數」與「狀態」。
6. 若清單沒有更新，點選「重新整理」。

### 完成後會看到什麼

畫面會列出目前可處理的待抄表帳單。若沒有可處理資料，會看到「目前沒有待抄表帳單」。

### 注意事項

- 「全物業抄表工作佇列」每一列仍需逐筆送出，不是整批一次送出。
- 若目前角色只能查看，畫面會提示「目前角色為查看模式」，抄表送出按鈕不會開放。
- 表格中的「歷史」按鈕目前是停用狀態，電表歷史需從「查看電表歷史」進入。

### 常見問題

**Q：為什麼看不到待抄表帳單？**  
A：可能目前沒有待抄表帳單，或目前角色只能查看。請先確認頁面提示與目前物業。

**Q：可以一次送出整棟抄表嗎？**  
A：目前畫面顯示每筆帳單都要分別點選「抄表」並送出。

## 新增抄表資料

### 適用情境

當某筆電費帳單狀態允許抄表，且你要輸入本期電表度數時，使用此操作。

[截圖：「送出抄表」，包含「本期電表度數（必填）」與「金額由系統計算」]

### 操作步驟

1. 在「帳單與抄表」頁面開啟「全物業抄表」或「帳單處理」。
2. 找到要處理的電費帳單。
3. 點選該列的「抄表」。
4. 在「送出抄表」抽屜中確認「房間」、「租客」、「帳單週期」與「上期度數」。
5. 在「本期電表度數（必填）」輸入本期讀數。
6. 點選「送出抄表」。

### 完成後會看到什麼

送出成功後，畫面會顯示「抄表已送出，帳單狀態已重新讀取。」清單會重新載入，該筆帳單狀態與金額會依系統更新。

### 注意事項

- 「本期電表度數（必填）」不可留空。
- 本期度數不可小於畫面顯示的「上期度數」。
- 「金額由系統計算」，使用者不需要手動輸入電費金額。
- 如果看到「資料已被更新」，請從更新後的清單重新開啟抄表。

### 常見問題

**Q：為什麼「抄表」按鈕不能按？**  
A：只有目前可抄表的電費帳單才會開放；若角色只能查看，也不能送出抄表。

**Q：送出後金額在哪裡看？**  
A：可開啟該筆「帳單詳情」查看「金額」、「本期度數」、「電費單價」與狀態。

## 查看電費計算結果

### 適用情境

當你要確認抄表送出後，帳單是否已計算用量、金額與狀態時，使用此操作。

[截圖：「帳單詳情」，包含「金額」與「此帳單尚未抄表」]

### 操作步驟

1. 進入「帳單與抄表」。
2. 在「帳單處理」頁籤中使用「選擇房間或租約」搜尋要查看的對象。
3. 確認目前位於「電費帳單」頁籤。
4. 需要時使用「帳單狀態」篩選。
5. 點選帳單列上的「詳情」。
6. 在「帳單詳情」中查看「金額」、「上期度數」、「本期度數」、「電費單價」、「抄表時間」與「狀態」。

### 完成後會看到什麼

「帳單詳情」會顯示該筆電費帳單的計算結果與狀態。若帳單已進入待收款，畫面會提示「此帳單已進入待收款」。

### 注意事項

- 若「金額」顯示「待系統計算」，代表目前畫面尚未取得可顯示金額。
- 「帳單詳情」中的收款資訊只反映目前帳單狀態，不代表所有財務報表總額。
- 若需要查看歷史讀數，請使用「查看此房間歷史」或「查看電表歷史」。

### 常見問題

**Q：為什麼金額不是我手動輸入？**  
A：目前抄表流程顯示「金額由系統計算」，使用者只輸入本期電表度數。

**Q：我要確認帳單是否已進入收款流程，看哪裡？**  
A：請在「帳單詳情」查看「狀態」；若看到「此帳單已進入待收款」，代表可依畫面操作收款。

## 查看電表歷史

### 適用情境

當你要回查物業或單一房間過去的電表紀錄、用量、金額與帳單狀態時，使用此操作。

[截圖：「物業電表歷史」，包含「目前篩選輔助摘要」與「帳單詳情」]

### 操作步驟

1. 從「帳單與抄表」頁面點選「查看電表歷史」。
2. 確認頁面標題為「物業電表歷史」或「房間電表歷史」。
3. 使用「年度」選擇要查看的年份。
4. 使用「月份」選擇「全年」或指定月份。
5. 查看「目前篩選輔助摘要」。
6. 在列表或表格中查看「房間」、「月份 / 期別」、「讀數」、「用量」、「狀態」與「帳單詳情」。

### 完成後會看到什麼

畫面會顯示目前篩選範圍內的電表歷史。若沒有資料，會看到「目前沒有電表歷史」或「此房間目前沒有符合條件的電表紀錄」。

### 注意事項

- 「目前篩選輔助摘要」只供快速檢視，正式應收、收入與財務總額請以財務報表頁為準。
- 「帳單詳情」在電表歷史頁只提供唯讀檢視，不處理收款、收據或抄表送出。
- 物業歷史與房間歷史可用的月份選項不同，請以畫面顯示為準。

### 常見問題

**Q：我在電表歷史頁找不到抄表按鈕。**  
A：電表歷史頁目前是唯讀檢視；抄表請回「帳單與抄表」處理。

**Q：摘要金額可以當作正式財務數字嗎？**  
A：不建議。畫面文字已提醒正式應收、收入與財務總額請以財務報表頁為準。

## 記錄營運費用

### 適用情境

當你要在日常作業中留下一筆含費用的營運紀錄時，使用此操作。目前可確認的畫面位於「日誌與維修」的「營運日誌」。

[截圖：「新增日誌」，包含「費用金額」與「會計科目」]

### 操作步驟

1. 從側邊選單進入「日誌與維修」。
2. 確認目前位於「營運日誌」。
3. 點選「新增日誌」。
4. 填寫「日誌內容（必填）」。
5. 若此日誌需要記錄費用，填寫「費用金額」。
6. 有費用金額時，選擇「會計科目」並視需要填寫「費用說明」。
7. 點選「儲存並重新載入」。

### 完成後會看到什麼

儲存成功後，畫面會顯示「日誌已建立。」列表中的該筆紀錄可能顯示「含費用」、「費用」與「會計科目」資訊。

### 注意事項

- 只有填寫費用金額時，畫面才會要求選擇「會計科目」。
- 既有費用日誌可調整金額與科目，但畫面提示「不能在此清除費用」。
- 若費用所屬月份已月結，畫面可能不允許改變會計影響。

### 常見問題

**Q：沒有費用的日誌可以不填費用金額嗎？**  
A：可以，畫面上的「費用金額」提示為「無費用可留空」。

**Q：費用日誌是不是會直接變成帳單？**  
A：本手冊只說明目前畫面可確認的營運日誌費用記錄，不承諾其他尚未出現在畫面上的入帳流程。
