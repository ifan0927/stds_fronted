# 09 常見問題與權限

本章適用於所有 STDS 管理後台使用者，說明看不到資料、無法登入、權限不足、操作失敗，以及什麼情況需要找系統管理員協助。內容以目前登入頁、側邊選單、「我的帳號」、「成員與權限」、成員詳情與共用頁面狀態可確認的畫面文字為準。

## 確認目前角色與可管理物業

### 適用情境

當你不確定自己目前能看哪些資料、能操作哪些功能，或要回報權限問題時，先使用此操作確認帳號狀態。

[截圖：「我的帳號」，包含「帳號資料」、「可管理物業」]

### 操作步驟

1. 登入 STDS 管理後台。
2. 查看頁首右側的角色標籤，例如「系統管理員」、「營運管理」、「工作室成員」或「業主」。
3. 點選頁首的「我的帳號」按鈕。
4. 在「我的帳號」頁查看「帳號資料」。
5. 確認畫面中的角色與可管理物業。
6. 若物業名稱暫時無法讀取，先記下畫面顯示的授權筆數與提示文字。

### 完成後會看到什麼

你會看到目前登入帳號的資料、角色與可管理物業。若物業名稱讀取失敗，畫面會提示「物業名稱暫時無法讀取」，但帳號資料仍可查看。

### 注意事項

- 角色會影響選單顯示與可執行操作。
- 可管理物業會影響你能看到哪些物業資料。
- 「我的帳號」可以更新顯示名稱，但角色、電子信箱與物業授權由系統管理。

### 常見問題

**Q：我看到的角色和預期不同怎麼辦？**
A：請聯絡系統管理員確認角色設定。

**Q：物業名稱暫時無法讀取，代表沒有權限嗎？**
A：不一定。請依畫面提示稍後重試；若持續發生，再請系統管理員協助確認。

## 看不到資料時處理

### 適用情境

當列表、報表或詳情頁沒有顯示預期資料，或畫面顯示「目前沒有資料」相關提示時，使用此操作。

[截圖：「列表無資料狀態」，包含「目前沒有符合條件的成員」、「清除篩選」]

### 操作步驟

1. 先確認頁首「目前物業」是否為你要處理的物業。
2. 若頁面有篩選欄位，確認篩選條件是否過窄。
3. 若畫面有「清除篩選」，可點選後重新查看。
4. 點選頁面上的「重新整理」或狀態畫面中的「重試」。
5. 若仍看不到資料，進入「我的帳號」確認角色與可管理物業。
6. 若確認仍不符合預期，請聯絡系統管理員。

### 完成後會看到什麼

若是物業或篩選條件造成的問題，重新選擇或清除篩選後會看到資料。若是角色或物業範圍造成的限制，需由系統管理員調整。

### 注意事項

- 「目前沒有資料」不一定是錯誤，可能代表目前物業或篩選條件下沒有符合資料。
- 日常作業頁面通常以「目前物業」為資料範圍。
- 不同角色看到的選單與操作可能不同。

### 常見問題

**Q：我確定資料存在，但畫面沒有顯示怎麼辦？**
A：請先確認目前物業與篩選條件，再重新整理；若仍沒有，請聯絡系統管理員。

**Q：我換物業後資料不一樣是正常的嗎？**
A：正常。日常作業資料會跟著目前物業切換。

## 無法登入時處理

### 適用情境

當你在登入頁無法進入後台，或看到登入相關提示時，使用此操作。

[截圖：「登入頁」，包含「STDS 管理後台」、「登入」]

### 操作步驟

1. 確認登入頁標題為「STDS 管理後台」。
2. 重新輸入「電子信箱」與「密碼」。
3. 若看到「請輸入電子信箱。」或「請輸入密碼。」，請補齊必填欄位。
4. 若看到「電子信箱或密碼不正確，請確認後再試一次。」，請再次確認輸入內容。
5. 若看到「登入嘗試次數過多，請稍後再試。」，請稍後再登入。
6. 若看到「帳號尚未開通」、「登入同步失敗」或「登入設定尚未完成」，請依畫面提示重試或聯絡管理員。

### 完成後會看到什麼

登入成功後會進入 STDS 管理後台，並看到「目前物業」、使用者資訊與角色標籤。若仍無法登入，畫面會保留提示供你判斷下一步。

### 注意事項

- 只能使用已開通的後台帳號登入。
- 若畫面顯示「登入狀態已失效」，請重新登入後繼續使用。
- 不要把密碼傳給他人代為測試。

### 常見問題

**Q：我看到「帳號尚未開通」怎麼辦？**
A：請聯絡管理員確認後台使用權限。

**Q：我看到「登入同步失敗」怎麼辦？**
A：可先點選畫面上的「重試」；若仍失敗，請聯絡管理員。

## 遇到沒有權限時處理

### 適用情境

當畫面顯示「沒有權限查看此頁」，或某些按鈕無法點選時，使用此操作。

[截圖：「沒有權限查看此頁」，包含「沒有權限查看此頁」、「回工作台」]

### 操作步驟

1. 先閱讀畫面提示，確認是否顯示「沒有權限查看此頁」。
2. 點選「回工作台」回到可使用的入口。
3. 查看頁首角色標籤。
4. 確認頁首「目前物業」是否正確。
5. 進入「我的帳號」確認可管理物業。
6. 若工作需要該頁面或操作，請聯絡系統管理員調整角色或物業範圍。

### 完成後會看到什麼

你會回到工作台或可查看的頁面。若權限確實不足，需要由系統管理員協助調整後才能使用。

### 注意事項

- 「沒有權限查看此頁」代表目前角色或目前物業不符合該頁面範圍。
- 按鈕停用不一定是錯誤，可能是目前角色只能查看，不能執行該操作。
- 請勿使用他人帳號代為操作。

### 常見問題

**Q：我昨天可以看，今天看不到怎麼辦？**
A：請先確認目前物業與登入帳號是否相同；若仍不一致，請系統管理員確認角色與物業範圍。

**Q：按鈕是灰色的代表壞掉嗎？**
A：不一定。畫面通常會搭配提示說明目前角色或狀態為何不能操作。

## 操作失敗時處理

### 適用情境

當你點選「儲存名稱」、「新增成員」、「建立並寄出設定信」、「儲存成員資料」、「儲存物業指派」、「重寄設定密碼信」、「寄送業主」或開啟報表後，畫面出現失敗提示時，使用此操作。

[截圖：「新增成員欄位提示」，包含「新增成員」、「請輸入 email。」]

### 操作步驟

1. 先停留在原頁面，不要重複快速點選同一按鈕。
2. 閱讀畫面上的失敗標題與說明。
3. 若畫面指出欄位問題，依欄位提示修正後再送出。
4. 若畫面提供「重試」，可點選「重試」。
5. 若是整頁載入失敗，可點選「回工作台」後重新進入該頁。
6. 若問題持續，請聯絡系統管理員並提供頁面名稱、操作名稱與提示文字。

### 完成後會看到什麼

若是暫時性問題，重試後可能成功。若是欄位、角色或資料範圍問題，需依畫面提示修正或請系統管理員協助。

### 注意事項

- 不要在送出中重複點選同一個送出按鈕，避免造成重複操作。
- 回報問題時，不需要提供密碼、完整個資或敏感金額。
- 若畫面提示資料已更新但頁首帳號暫時無法同步，請重新整理或重新登入後確認。

### 常見問題

**Q：我可以只把錯誤畫面截圖給管理員嗎？**
A：可以，但請遮蔽不必要的個資或敏感金額，並補充你剛剛點選的操作名稱。

**Q：操作失敗後要不要立刻重整？**
A：先讀完畫面提示；若有欄位錯誤，修正欄位即可，不一定要重整。

## 判斷哪些情況要找系統管理員

### 適用情境

當你不確定問題能否自行處理，或需要調整帳號、角色、物業範圍時，使用此操作。

[截圖：「我的帳號權限確認」，包含「角色」、「可管理物業」]

### 操作步驟

1. 先確認目前頁面名稱與目前物業。
2. 查看頁首角色標籤。
3. 進入「我的帳號」確認可管理物業。
4. 記下畫面上的提示文字，例如「沒有權限查看此頁」或「登入設定尚未完成」。
5. 若涉及角色、物業範圍、帳號開通或停用按鈕，聯絡系統管理員。
6. 回報時提供頁面名稱、操作名稱、目前角色、目前物業與提示文字。

### 完成後會看到什麼

系統管理員可以依你提供的資訊確認帳號、角色或物業範圍。若是暫時性操作失敗，也能依提示文字判斷下一步。

### 注意事項

- 找系統管理員時不需要提供密碼。
- 若問題與某個物業有關，請務必提供目前物業名稱。
- 若問題與某個月份報表有關，請提供年度與月份，但避免傳送敏感金額。

### 常見問題

**Q：哪些情況一定要找系統管理員？**
A：帳號尚未開通、角色不符、可管理物業不符、看到沒有權限、或需要新增與調整成員時，請找系統管理員。

**Q：我只是不知道畫面怎麼操作，也要找系統管理員嗎？**
A：可以先查本手冊對應章節；若手冊沒有提到或畫面與手冊不同，再請系統管理員協助確認。

## 了解角色可操作範圍

### 適用情境

當你要判斷某個選單或按鈕為什麼看不到、不能點，或要協助新成員確認角色差異時，使用此操作。

[截圖：「成員與權限」，包含「角色篩選」、「新增成員」]
[截圖：「成員詳情權限」，包含「管理資料」、「物業指派」]

### 操作步驟

1. 查看頁首角色標籤。
2. 使用側邊選單確認目前可見入口。
3. 若看不到「成員與權限」，確認目前角色是否為「業主」。
4. 若進入「成員與權限」，確認是否看得到「新增成員」。
5. 若進入成員詳情，確認「管理資料」與「物業指派」區塊是否顯示「限系統管理員」或「操作未開放」。
6. 若需要超出目前角色的操作，請聯絡系統管理員。

### 完成後會看到什麼

你可以從側邊選單、按鈕狀態與提示文字判斷目前角色可查看或可操作的範圍。

### 注意事項

- 「系統管理員」、「營運管理」、「工作室成員」與「業主」是目前畫面可確認的角色標籤。
- 「品牌內容」目前只會在部分管理角色顯示。
- 「成員與權限」不會對業主角色顯示。
- 成員詳情中的「管理資料」與「物業指派」目前標示為限系統管理員。

### 常見問題

**Q：「營運管理」可以新增所有角色嗎？**
A：目前畫面可確認「營運管理」會看到「新增成員」，但新增表單的角色選項可能受限制；實際可建立角色請以畫面選項為準。

**Q：「工作室成員」可以新增成員嗎？**
A：目前畫面會顯示停用的「新增成員」與「目前角色僅能查看成員列表。」提示。

**Q：「業主」可以看到成員與權限嗎？**
A：目前側邊選單不會對業主角色顯示「成員與權限」。
