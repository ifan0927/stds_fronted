# 08 報表與匯出

本章適用於需要在「報表中心」查看物業財務資料、開啟系統產生報表、查看房客名冊，或處理報表開啟失敗的使用者。內容以目前「報表中心」畫面可確認的文字為準。

## 查看月報

### 適用情境

當你要查看某個物業指定月份的收入、支出、淨額與月報明細時，使用此操作。

[截圖：「報表中心月報明細」，包含「年度」、「月報明細」]

### 操作步驟

1. 先在頁首確認「目前物業」是要查看的物業。
2. 從側邊選單進入「報表中心」。
3. 在頁面上方確認標題為「報表中心」。
4. 使用「年度」選擇要查看的年份。
5. 使用「月份」選擇要查看的月份。
6. 查看「選取月份收入」、「選取月份支出」與「選取月份淨額」。
7. 在「月報明細」表格查看各筆明細。

### 完成後會看到什麼

頁面會顯示選取月份的摘要數字、資料狀態，以及「月報明細」表格。明細表格目前可看到「日期」、「科目」、「類別」、「來源」、「房間」、「租客」、「期別」、「摘要」與「金額」。

### 注意事項

- 「已月結」代表目前選取月份已標示為月結資料；「即時資料」代表資料仍可能隨後續作業更新。
- 若「月報明細」顯示「此月份目前沒有財務報表。」或「此月份目前沒有報表明細。」，請先確認年度、月份與目前物業是否正確。
- 金額若顯示「未提供」，代表該欄位目前沒有可顯示的數字。

### 常見問題

**Q：我只想切換月份，需要離開頁面嗎？**
A：不需要。直接使用「年度」與「月份」欄位切換即可。

**Q：「已月結」與「即時資料」要怎麼判斷？**
A：請以畫面上的狀態標籤為準；若要送出或對外使用報表，請先確認狀態是否符合內部作業規則。

## 查看年度月份摘要

### 適用情境

當你想快速比較同一年度各月份的收入、支出與淨額，或從年度列表切到某個月份明細時，使用此操作。

[截圖：「報表中心月份摘要」，包含「年月份摘要」、「明細」]

### 操作步驟

1. 進入「報表中心」。
2. 使用「年度」選擇要查看的年份。
3. 找到目前年度的月份摘要區塊，例如「2026 年月份摘要」。
4. 在表格中查看「月份」、「收入」、「支出」與「淨額」。
5. 若要查看某個月份明細，點選該列的「明細」。
6. 等待頁面切換到該月份。

### 完成後會看到什麼

頁面上方的月份標籤與「月報明細」會改為你選擇的月份，摘要數字也會同步更新。

### 注意事項

- 年份摘要區塊只顯示目前選取年度的報表摘要。
- 若顯示「此年度目前沒有報表摘要。」，請改選其他年度或確認目前物業是否正確。
- 「淨額」可能為正數或負數，請搭配收入與支出一起判讀。

### 常見問題

**Q：點「明細」後沒有看到我預期的資料怎麼辦？**
A：請再次確認頁面上方的年度、月份與目前物業是否正確。

## 開啟收支表、損益表與營運報告

### 適用情境

當你需要開啟目前月份，或年度摘要中某個月份的「收支表」、「損益表」或「營運報告」時，使用此操作。

[截圖：「報表中心報表按鈕」，包含「收支表」、「營運報告」]

### 操作步驟

1. 進入「報表中心」。
2. 確認目前物業、年度與月份。
3. 若要開啟目前選取月份的報表，點選頁面上方的「收支表」、「損益表」或「營運報告」。
4. 若要開啟年度摘要中其他月份的報表，先在年份摘要區塊找到該月份。
5. 在該月份列點選「收支表」、「損益表」或「營運報告」。
6. 等待報表預覽視窗開啟。

### 完成後會看到什麼

報表會在新的預覽視窗中開啟。成功時，頁面會出現「收支表已開啟。」、「損益表已開啟。」或「營運報告已開啟。」的提示。

### 注意事項

- 若瀏覽器阻擋預覽視窗，畫面會提示「瀏覽器阻擋了報表預覽視窗，請允許彈出視窗後再試一次。」。
- 開啟報表前請先確認年度、月份與目前物業，避免查看到不同期間的資料。
- 報表預覽內容由系統產生；請不要在預覽視窗中手動修改後當作正式資料。

### 常見問題

**Q：點了報表按鈕但沒有新視窗怎麼辦？**
A：請依畫面提示允許彈出視窗，再重新點選同一個報表按鈕。

**Q：年度摘要列上的報表按鈕和頁面上方的報表按鈕有什麼差別？**
A：頁面上方按鈕開啟目前選取月份；年度摘要列上的按鈕開啟該列月份。

## 開啟房客名冊

### 適用情境

當你需要依指定基準日查看目前物業的「房客名冊」時，使用此操作。

[截圖：「報表中心其他匯出」，包含「房客名冊」、「開啟名冊」]

### 操作步驟

1. 進入「報表中心」。
2. 找到「其他匯出」區塊。
3. 在「房客名冊」下方設定「房客名冊基準日」。
4. 在「房客名冊空房設定」選擇「包含空房」或「只列出租中」。
5. 點選「開啟名冊」。
6. 等待房客名冊預覽視窗開啟。

### 完成後會看到什麼

房客名冊會在新的預覽視窗中開啟。成功時，頁面會出現「房客名冊已開啟。」的提示。

### 注意事項

- 「房客名冊基準日」會影響名冊呈現的租住狀態。
- 「包含空房」會把空房列入名冊；「只列出租中」只顯示出租中的項目。
- 開啟前請先確認目前物業，房客名冊以目前物業為範圍。

### 常見問題

**Q：我想看某一天的名冊，要改哪個欄位？**
A：請調整「房客名冊基準日」。

**Q：名冊不想包含空房怎麼辦？**
A：請在「房客名冊空房設定」選擇「只列出租中」後再點選「開啟名冊」。

## 寄送業主財務報表

### 適用情境

當你需要從「報表中心」送出目前月份的財務報表寄送流程時，使用此操作。此操作目前只對可執行寄送的角色開放。

[截圖：「確認寄送財務報表」，包含「目前資料狀態」、「送出寄送流程」]

### 操作步驟

1. 進入「報表中心」。
2. 確認目前物業、年度與月份。
3. 查看頁面上的資料狀態是「已月結」或「即時資料」。
4. 點選「寄送業主」。
5. 在「確認寄送財務報表」視窗中再次確認月份與資料狀態。
6. 點選「送出寄送流程」。
7. 若不送出，點選「取消」。

### 完成後會看到什麼

送出成功時，畫面會提示「財務報表寄送流程已送出。」並重新整理報表資料。

### 注意事項

- 若「寄送業主」無法點選，請查看提示；畫面可能顯示目前角色只能查看報表，無法寄送業主。
- 確認視窗會顯示目前資料狀態，但不顯示收件人名單或寄送進度。
- 送出前請確認月份與資料狀態，避免寄送錯誤期間的報表。

### 常見問題

**Q：為什麼我看得到「寄送業主」但不能點？**
A：目前角色可能只能查看報表，無法寄送業主；請聯絡系統管理員確認角色。

**Q：送出後可以在這個畫面看寄送進度嗎？**
A：目前畫面不顯示收件人名單或寄送進度。

## 判讀報表數字

### 適用情境

當你需要快速理解報表中心的收入、支出、淨額與明細金額時，使用此操作。

[截圖：「報表中心摘要數字」，包含「選取月份收入」、「選取月份淨額」]

### 操作步驟

1. 進入「報表中心」並選定年度、月份。
2. 查看「選取月份收入」，確認該月份收入總額。
3. 查看「選取月份支出」，確認該月份支出總額。
4. 查看「選取月份淨額」，確認收入扣除支出後的結果。
5. 在「月報明細」查看「類別」、「來源」、「摘要」與「金額」。
6. 若需要追查月份差異，回到年份摘要區塊比較不同月份。

### 完成後會看到什麼

你可以從三個摘要數字掌握該月份的整體結果，並從「月報明細」查看組成項目。

### 注意事項

- 「淨額」不是單一收款項目，而是收入與支出加總後的結果。
- 「類別」目前可能顯示租金收入、電費收入、押金退還、押金扣抵、租金退回或日誌支出等類型。
- 「來源」目前可能顯示帳單、日誌、租約或「來源未提供」。

### 常見問題

**Q：我看到負數金額代表什麼？**
A：請搭配該列的「類別」、「來源」與「摘要」判斷；若仍無法確認，請回到相關作業頁查核原始紀錄。

**Q：表格出現「未提供」怎麼辦？**
A：代表該欄位目前沒有可顯示內容，請改用其他欄位交叉確認。

## 報表或名冊無法開啟時處理

### 適用情境

當點選「收支表」、「損益表」、「營運報告」或「開啟名冊」後，畫面出現無法開啟、載入失敗或權限提示時，使用此操作。

[截圖：「報表無法開啟提示」，包含「無法開啟」、「重試」]

### 操作步驟

1. 先閱讀畫面上的錯誤提示。
2. 若提示此月份報表尚不存在，請更換年度或月份後再試一次。
3. 若提示目前帳號沒有存取權限，請確認目前物業與角色。
4. 若畫面提供「重試」，可點選「重試」再次開啟。
5. 若仍無法開啟，點選「重新整理」後再試一次。
6. 若問題持續，請聯絡系統管理員並提供目前物業、年度、月份與你看到的提示文字。

### 完成後會看到什麼

若問題是暫時性的，重試或重新整理後可能會成功開啟報表。若是權限或資料範圍問題，需由系統管理員協助確認。

### 注意事項

- 請不要自行改用未授權帳號查看報表。
- 回報問題時，不需要提供真實租客個資或報表金額。
- 若只有特定月份無法開啟，請一併提供該月份資訊，方便管理員確認。

### 常見問題

**Q：看到「收支表無法開啟」時要先做什麼？**
A：先確認年度、月份與目前物業，再依畫面是否提供「重試」進行重試。

**Q：我可以截圖給管理員嗎？**
A：可以，但請避免截到不必要的個資或敏感金額。
